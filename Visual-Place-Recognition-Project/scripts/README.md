# Scripts Folder

This folder is for experiment runner scripts that use the provided baseline VPR code.

Suggested script names:
- `run_retrieval.py`
- `run_matching.py`
- `evaluate_recall.py`

Important: do not rewrite a new VPR system from scratch. The project requires using the provided baseline code and adapting it for:
- retrieval experiments
- distance metric comparison
- image matching / re-ranking
- evaluation on the given datasets
