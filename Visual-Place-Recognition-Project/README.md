# Visual Place Recognition Project

This project aims to build a visual place recognition (VPR) system using Python and computer vision.

## Project goal

The first version will:
- load images from a dataset
- extract visual features from each image
- compare images to recognize if they show the same or similar places
- provide a simple command-line interface to test recognition results
